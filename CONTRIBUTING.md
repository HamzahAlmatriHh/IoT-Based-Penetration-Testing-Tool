# Contributing

Use a feature branch and a focused pull request. Install development dependencies, run `ruff check app.py tests`, `pytest -q`, `npm run check`, and the firmware build when firmware changes. Add tests for behavior changes.

Never submit credentials, private evidence, real target data, offensive payloads, HID injection, persistence, C2, stealth, or automated host execution. Report vulnerabilities privately as described in `SECURITY.md`.
